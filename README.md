# P. Rahul Reddy — Edge AI & Computer Vision Portfolio

My personal portfolio website, showcasing projects and credentials in Edge AI, Machine Learning, and Computer Vision.

[View Live Portfolio](https://prahulredd.github.io/Portfolio/)

## Tech Stack
*   **Framework**: React + Vite
*   **Styling**: Tailwind CSS
*   **Animations**: Motion (Framer Motion)
*   **Interactivity**: tsParticles

## Quick Start
```bash
npm install
npm run dev
```
